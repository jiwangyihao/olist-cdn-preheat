# OpenList CDN Preheat

A desktop application to preheat CDN caches for OpenList/AList sites.

## Tech Stack

- Nuxt 4
- Tauri 2
- NuxtUI v4
- TailwindCSS v4
- Typescript

## Setup

```sh
# install dependencies
$ bun install

# start the project
$ bun run tauri:dev
```

## Build

```sh
$ bun run tauri:build
```
